# Projeto Cypress
[**Demonstração em vídeo do projeto**](https://www.linkedin.com/feed/update/urn:li:activity:7291088704444506112/)

Feito com base na aplicação [**ServeRest**](https://serverest.dev/)

## Tecnologias Usadas
* **Cypress** (Framework de testes)
* **Javascript** (Linguagem de código principal)
* **Mochawesome** (Criação de reports)
* **Github Actions** (Pipeline usada na execução dos testes)

## Resumo do projeto
Projeto feito no intuito de utilizar todas as técnicas para testes que o [*Cypress*](https://docs.cypress.io/app/get-started/why-cypress) oferece,foi feito em cima da aplicação [**ServeRest**](https://serverest.dev/),testando todas as suas frentes (frontend,backend e funcional) com vários casos de testes para cada uma delas,utilizando-se do [*Github Actions*](https://github.com/features/actions) para realizar toda a bateria de testes na pipeline, e gerando os reports de maneira automática com o 
[*Mochasome*](https://www.npmjs.com/package/mochawesome),o projeto foi um sucesso como o meu primeiro exercício dessa escala com o Cypress,quando me permitiu aprender muito do que o framework tem a oferecer.
